# 好視TV (Better WebTV) — 長輩友善的 Android TV 網頁全螢幕電視殼

專為長輩與家庭客廳設計的通用 **Android TV 網頁全螢幕電視殼（WebView Wrapper）**，將一般網頁影音頁面包裝成如傳統電視般直覺的遙控器操作體驗，不卡網頁選單、不怕誤觸退出。

---

## 長輩怎麼看電視（遙控器操作）

- **上 / 下鍵（或頻道上下鍵）**：上鍵往較小台號切換（如 `3 → 2 → 1`）、下鍵往較大台號切換（如 `1 → 2 → 3`），左下角顯示大字體台號、頻道圖示與台名，幾秒後自動淡出。
- **左 / 右鍵**：從螢幕左側滑出**半懸浮頻道清單**（顯示各頻道圖示與大字體台名），按上/下選擇、OK 確認播放，約 8.5 秒未操作或再按左/右/返回鍵自動收起。
- **數字鍵 0–9**：直接輸入台號切台（例如按 `1` 跳到第 1 台、`2` 跳到第 2 台）。
- **OK / 確認鍵（短按）**：畫面卡住時直接重新整理目前頻道（內建 **3 秒冷卻保護**，避免連續誤觸或重複連按導致頻繁重整請求）。
- **返回鍵**：需要連續按兩次才會離開 App，防止長輩誤觸跳回電視桌面。
- **自動全螢幕**：載入使用者設定的頻道網頁後，自動偵測頁面中的 HTML5 `<video>` 元素並撐滿全螢幕播放，同時記住上次觀看的頻道。

## 家人怎麼設定頻道與登入帳號

### 1. 開啟「家人設定中心」（隱藏入口，避免長輩誤觸）
- **長按遙控器 OK / 確認鍵 2 秒**，或按遙控器上的 **選單鍵 (Menu / Settings / Info)**。

### 2. 網頁帳號登入模式（選用）
若您使用的合法串流或影音網頁需要登入帳號：
1. 在「家人設定中心」選擇 **「帳號登入模式（開啟遙控器游標）」**。
2. 用方向鍵移動畫面上的白色滑鼠游標、OK 鍵點擊進行網站登入或操作（WebView 會依標準瀏覽器機制保存 Cookie 與受保護媒體權限）。
3. 登入完成後按 **返回鍵**，就會自動恢復全螢幕看電視模式。

### 3. 設定頻道網頁網址與圖示（兩種方式任選／並用）

#### 方式 A：手機掃 QR Code（同區網最方便）
1. 在「家人設定中心」用手機掃描左側 QR Code（手機與電視需在同一個 Wi-Fi / 區網，預設通訊埠 `8088`）。
2. 在手機網頁中直接編輯：**台號**（如 `1`、`2`、`3`）、**頻道名稱**、**頻道網頁網址**（例如 `https://example.com/channel/1`）、**頻道圖示圖片網址**（支援 PNG / JPG / SVG；留空則自動顯示高對比台標色塊）。
3. 按下 **「儲存並套用到電視」**，電視端立刻更新清單並生效。
4. 小技巧：在電視「帳號登入模式」瀏覽器點進想設為頻道的網頁後，手機端點一下 **「帶入電視目前網址」** 即可快速抓下該網頁網址！

#### 方式 B：遠端 JSON 自動同步（人不在長輩家也能遠端改）
1. 將頻道清單上傳到 GitHub Gist（格式可參考專案中的 [sample-channels.json](sample-channels.json)），取得 Raw 連結。
2. 在手機掃描開啟的管理網頁中，貼上該網址並勾選 **「電視每次開啟 App 時自動同步最新清單」**。
3. 之後你在遠端更新 Gist，長輩重開 App 時就會自動同步最新頻道設定。

## 安裝與編譯

```powershell
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
.\gradlew.bat testDebugUnitTest assembleDebug
```

編譯完成後的 APK 位於：
`app/build/outputs/apk/debug/app-debug.apk`

透過 ADB 安裝到 Android TV：
```powershell
adb connect <電視IP>:5555
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
